# University Course Management System

This is Web Lab 3. It manages student data using Node.js and ES6 JavaScript.

## Files in this Project

* package.json: Contains "type: "module" so Node can use import and export.
* models.js: Has the Student class and makes the student id read only using Object define property.
* database.js: Simulates fetching student data after a 2-second delay.
* analytics.js: Has functions to calculate class averages, find the top student, and filter students.
* main.js: Runs the whole project and prints the final report in the console.
